# Heimdall (HMDL)

**Guild management, event coordination, and resource planning for Ragnarok Online communities.**

Heimdall is a guild management platform built for **Ragnarok Online Origin Classic (ROOC)** and **Ragnarok 3 (RO3)**. It brings the day-to-day work of running a competitive guild into one place: managing members, organising events, building rosters, coordinating attendance, and handling guild resources.

- **Live application:** https://hmdl.vercel.app
- **Official Discord:** https://discord.gg/vKFSbyGCxf

---

## What Heimdall offers

### Guild and member management
- Centralised guild workspace and member roster.
- Guild roles and management permissions.
- Member information and character details.
- Tools designed around the operational needs of ROOC and RO3 guilds.

### Event management
- Create and manage guild events, including supported ROOC event formats and configurable RO3 events.
- Configure event schedules, time zones, battlefields, and party capacity.
- Generate recurring events automatically.
- Keep historical event settings with event configuration snapshots.
- View and manage upcoming and past events.

### Attendance coordination
- Let members submit availability directly in Heimdall.
- Three attendance responses: Available, Unavailable, and AFK / Busy.
- Track response counts and member responses.
- Lock attendance ahead of an event.
- Send attendance prompts and reminders through the Discord integration.
- Keep attendance information synchronised with event planning.

### Rosters and party organisation
- Create manual rosters or generate rosters automatically.
- Organise members into parties and battlefields.
- Edit assignments, move members between slots, and manage roster configurations.
- Group parties into raids for larger-scale coordination.
- Support role and job overrides where needed.

### Resource management
- Configure guild resource and reward types.
- Manage resource availability and allocations.
- Let members opt in to eligible resource pools.
- Coordinate resource distribution with guild-specific rules and limits.
- Support bidding and rotation workflows for guild resource management.

### Event results and records
- Upload event result screenshots.
- Keep event results attached to the relevant event.
- Browse an event's historical result archive.
- Store uploaded screenshots privately.

### Discord integration
- Connect guild operations with Discord.
- Publish event attendance prompts and reminders.
- Allow members to respond to attendance prompts through Discord.
- Use Discord as a companion to the Heimdall guild workspace.

## Built for ROOC and RO3

Heimdall supports the different workflows used by Ragnarok Online communities:

| Area | ROOC | RO3 |
| --- | --- | --- |
| Guild and member management | Yes | Yes |
| Guild event workflows | Guild League and Emperium Overrun | Configurable RO3 events |
| Attendance coordination | Supported | Supported |
| Roster and party management | Supported | Supported |
| Resource management | Supported | Supported |
| Discord integration | Supported | Supported |

Feature availability and workflows may differ between game modes.

## Getting started

1. Open the [Heimdall application](https://hmdl.vercel.app).
2. Sign in and create or join your guild using the available onboarding flow.
3. Invite the guild's managers and members.
4. Configure your guild's events, resources, and Discord integration.
5. Start coordinating your guild from one workspace.

For help, announcements, feedback, and community support, join the **[official Heimdall Discord server](https://discord.gg/vKFSbyGCxf)**.

## Technology

Heimdall is built with a modern web application stack, including:

- [Next.js](https://nextjs.org/) and React
- TypeScript
- Prisma
- PostgreSQL
- Discord integration
- Vercel for application hosting
